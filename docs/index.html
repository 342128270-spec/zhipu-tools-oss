zhipu-tools-oss

智谱开放平台工具 API 的开源自建替代 · 本地运行 · 无 API Key · 无计费8/8 通过

把 base_url 从 https://open.bigmodel.cn/api 换成 http://127.0.0.1:8088，客户端代码不用改。

安装

git clone <repo> && cd zhipu-tools-oss
./install.sh    # 建 venv，装依赖
./start.sh      # 127.0.0.1:8088

调用

curl -s http://127.0.0.1:8088/paas/v4/web_search \
  -H "Content-Type: application/json" \
  -d '{"search_query":"智谱 GLM","count":5}'

设计取舍

选择原因
搜索走 HTML 解析无需 Key；被反爬时返回空并在 errors 说明
检索用 BM25 而非向量库不下载模型、零内存占用，词面命中够用
OCR 用系统 Vision离线、中文准、不下载权重
批处理只做转发不产 token，负责排队与落盘
